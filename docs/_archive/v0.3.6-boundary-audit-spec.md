# v0.3.6 — Syscall/VFS/ELF Boundary Audit Implementation Spec

**Status:** Implementation spec (Target: v0.3.6)
**Source:** `audits/boundary+syscall_audit.md` — verified kernel audit, 12 of 21
claims confirmed as real defects.
**Scope:** syscall layer, VFS core, FAT32/tmpfs/devfs backends, ELF loader.
**Referenced from:** `ROADMAP.md` §v0.3.6.

---

## 1. Problem Statement

A user task (Ring 3) can reach kernel memory corruption, cross-domain
information disclosure, authorization-bypass TOCTOU, and CPU-monopolising
busy-waits through four syscall-layer and ELF-loader attack surfaces:

1. **Unvalidated raw Ring-3 pointers** in `sys_fstat` and `sys_ioctl` — an
   arbitrary-kernel-write primitive and an unvalidated pointer handed to device
   drivers.
2. **Authorize-then-resolve TOCTOU** in every path syscall — a concurrent task
   can change the object identity between `vfsd_authorize` (blocking IPC) and
   the actual filesystem operation.
3. **Unsynchronized `Vnode::refcount` / `FdTable` mutation** across
   `sys_chdir`/`sys_dup`/`sys_dup2`/`FdTable::free` — lost-update races leading
   to use-after-free or refcount leak.
4. **ELF loader gaps** — uniform W/X page permissions (no NX on stack/heap),
   OOB file-buffer read via unchecked `phdr->offset+filesz`, unbounded
   `argv`/`envp` scans, and unbounded user-stack underflow.
5. **Unbounded busy-wait** (`UINT64_MAX` pause-spin) in `tty_read`/`kbd_read`
   and an unbounded blocking `sys_receive` (no timeout variant) — WCET/liveness
   violations.

All fixes are zero-allocation: `CheckedPtr` is stack-resident, refcount uses
atomic builtins on the existing `int` field, and every new bound is a
compile-time constant.

---

## 2. Design Principles (binding for v0.3.6)

1. **Validate at the boundary, once.** The syscall handler is the enforcement
   point for every Ring-3 pointer. A pointer must be wrapped in `checked()`
   and validated before any dereference, mirroring the existing
   `sys_stat`/`sys_readdir`/`sys_read`/`sys_write` pattern.
2. **Resolve once, operate on the resolved object.** No path syscall
   re-resolves after authorization without re-validating object identity.
3. **Every refcount mutation is atomic and race-free.** Use the return value
   of the atomic decrement (previous value) for the zero-check — never
   re-read the counter.
4. **W^X is enforced in the PTE, not just nominally in validation.** Segment
   permissions derive from `phdr->flags`; the user stack and heap are
   writable-only.
5. **Every blocking kernel primitive reachable by a task is bounded or
   deschedules.** No `UINT64_MAX` spin; blocking receive has a timeout
   variant.
6. **Freestanding constraint:** `<atomic>` is NOT available (`-nostdinc`).
   Atomicity uses GCC/Clang builtins (`__atomic_fetch_add`,
   `__atomic_fetch_sub`, `__atomic_load_n`, `__atomic_store_n`) directly on
   the existing `int` field — same lock-free semantics as `std::atomic<int>`,
   zero footprint change.

## 3. Target Architecture

```
Ring-3 task ──syscall──▶ Syscall::sys_* (boundary validation)
                              │
                              ├─ checked()/CheckedPtr<T> ──▶ .unsafe_ptr() only
                              │     after .valid()
                              ├─ vfs::resolve() ──▶ capture ino + fs instance
                              │     (VULN-C4 resolve-first)
                              ├─ vfsd_authorize() (blocking IPC)
                              │     └─ re-resolve + identity compare
                              ├─ operate on already-resolved vnode
                              └─ atomic refcount ops (__atomic_fetch_*)
```

## 4. Implementation Steps

Each step is gated by a full `make execute-test x86_64 debug all` run
(expected 881/881) before the next step begins.

### Step 1 — VULN-C1: `sys_fstat` raw Ring-3 pointer deref

**File:** `src/kernel/syscall/syscall_handlers_fs.cpp`, `Syscall::sys_fstat`
(currently lines ~201-215).

Current:
```cpp
// NOLINTNEXTLINE(performance-no-int-to-ptr)
auto *st = reinterpret_cast<vfs::VfsStat *>(arg1);
return static_cast<uint64_t>(f->vnode->ops->fstat(*f->vnode, *st));
```

Fix (mirror `sys_stat` at lines ~357-361):
```cpp
// NOLINTNEXTLINE(performance-no-int-to-ptr)
auto st = checked(reinterpret_cast<vfs::VfsStat *>(arg1));
if (syscall_is_user_task() && !st.valid())
    return static_cast<uint64_t>(-1);
return static_cast<uint64_t>(f->vnode->ops->fstat(*f->vnode, *st.unsafe_ptr()));
```

**Side-conditions:** `checked()` is already included
(`kernel/memory/checked_ptr.hpp`). No callers change. `VfsStat` is
trivially copiable (two scalar fields) — satisfies the `TriviallyCopiable`
constraint.

### Step 2 — VULN-C2: `sys_ioctl` forwards unchecked Ring-3 pointer

**Files:**
- `src/kernel/syscall/syscall_handlers_fs.cpp` — `Syscall::sys_ioctl`
- `src/kernel/vfs/vfs.hpp` — `VnodeOps::ioctl` signature
- All `*_ioctl` stubs: `devfs.cpp`, `fat32_fs.cpp`, `pipe.cpp`, `procfs.cpp`,
  `tmpfs.cpp` (`nullptr` entries), `initrd_fs.cpp`.

2a. Change `VnodeOps::ioctl` (vfs.hpp:85) from:
```cpp
int (*ioctl)(Vnode &self, uint64_t request, void *arg);
```
to:
```cpp
int (*ioctl)(Vnode &self, uint64_t request, kernel::CheckedPtr<void> arg);
```

2b. Update every `*_ioctl` stub to the new signature. Stubs that ignore the
argument use `CheckedPtr<void>` (implicitly constructed from `nullptr`
via the default constructor) — e.g.:
```cpp
static int tty_ioctl(Vnode &, uint64_t, kernel::CheckedPtr<void>) {
    return VFS_INVALID;
}
```
(`CheckedPtr` is in `namespace kernel`; inside `vfs` namespace use
`kernel::CheckedPtr<void>`.)

2c. In `sys_ioctl` (currently lines ~298-311), validate at the boundary:
```cpp
auto arg_chk = checked(reinterpret_cast<uint8_t *>(arg2), sizeof(uint64_t));
if (syscall_is_user_task() && arg2 != 0 && !arg_chk.valid())
    return static_cast<uint64_t>(-1);
return static_cast<uint64_t>(
    f->vnode->ops->ioctl(*f->vnode, arg1,
                         // NOLINTNEXTLINE(performance-no-int-to-ptr)
                         reinterpret_cast<CheckedPtr<void>>(checked(
                             reinterpret_cast<uint8_t *>(arg2)))));
```

**Caveats:** `CheckedPtr<void>` — `void` is not `TriviallyCopiable`. The
audit prescribes `CheckedPtr<void>` but the template constrains `T` to
`TriviallyCopiable`. **Adaptation:** use `CheckedPtr<uint8_t>` as the
parameter type instead of `CheckedPtr<void>`; all stubs are signature-only
and never dereference, and the syscall boundary already validated the
minimum 8-byte window. If a future driver needs command-specific sizes it
calls `checked(arg.unsafe_ptr(), cmd_size).valid()` before use.
`checked(ptr)` with default count=1 gives a 1-byte validated window at the
boundary, which is the smallest addressable unit.

### Step 3 — VULN-C4: authorize-then-resolve TOCTOU

**Files:**
- `src/kernel/vfs/vfsd.hpp` — `Msg` gains `uint64_t ino` field
- `src/kernel/syscall/syscall_handlers_fs.cpp` — `sys_open`, `sys_stat`,
  `sys_mkdir`, `sys_unlink`, `sys_rmdir`, `sys_chdir` + a shared helper
- `src/kernel/vfs/vfs.cpp` — must expose the resolved identity

3a. Add `uint64_t ino` to `vfsd::Msg` (vfsd.hpp:48). The struct is fixed-size
(padded `path[32]` → 8-byte-aligned `arg1` field exists; add `ino` after
`arg1`). **Zero allocation** — total size stays a small multiple of 8.

3b. Add a resolve helper that returns both the vnode and its identity:
```cpp
static bool resolve_for_authorize(const char *path, vfs::Vnode *&out_vnode,
                                  uint64_t &out_ino, uint64_t &out_fs);
```
`out_ino = vn->ino`; `out_fs` = pointer-to-fs-instance, encoded from
`vn->private_data`/mount owner (see vfs.cpp resolve). Use the resolved
`vnode` pointer as the fs-instance discriminator (stable within a mount).

3c. Rewrite each path syscall as **resolve-first**:
```cpp
vfs::Vnode *vn = nullptr;
uint64_t ino = 0;
uint64_t fs_id = 0;
if (!resolve_for_authorize(path, vn, ino, fs_id) || !vn)
    return static_cast<uint64_t>(-1);
if (!vfsd_authorize(op_type, pid, path, ino))   // carries ino in Msg
    return static_cast<uint64_t>(-1);
// Re-resolve and compare identity — object changed during auth window?
vfs::Vnode *vn2 = nullptr;
uint64_t ino2 = 0, fs_id2 = 0;
if (!resolve_for_authorize(path, vn2, ino2, fs_id2) ||
    vn2 != vn || ino2 != ino || fs_id2 != fs_id)
    return static_cast<uint64_t>(-1);
// Operate on vn2 (already-resolved), never re-resolve a third time.
```

3d. Update `vfsd_authorize` signature to accept the captured `ino` and copy it
into `msg.ino`.

**Caveats:** `vfs::resolve` itself is unlocked (documented; single-core +
IRQ-off model). The compare-on-resolve closes the *authorization-window*
TOCTOU; it does not lock the object for the operation duration (out of scope
for v0.3.6, noted in ROADMAP deferred). vfsd daemon side must tolerate the
extra `ino` field (opaque to existing logic). `sys_open` must pass `vn2` to
`syscall_task_open` (not a path re-resolve) — add
`syscall_task_open(vfs::Vnode*, uint64_t flags)` path (already declared in
`syscall_helpers.hpp:43`).

### Step 4 — VULN-C5/C6: atomic `Vnode::refcount` + `FdTable` + `cwd_lock_`

**Files:**
- `src/kernel/vfs/vfs.hpp` — `Vnode::refcount` stays `int`; documented as
  atomic-intended
- `src/kernel/vfs/vfs.cpp` — `FdTable::free`, `FdTable::free_err`
- `src/kernel/syscall/syscall_handlers_fs.cpp` — `sys_dup`, `sys_dup2`,
  `sys_chdir`
- `src/kernel/task/task.cpp` — refcount mutations in clone/cleanup
- `src/kernel/task/task.hpp` — `TaskControlBlock::cwd_lock_`
- `src/services/shell.cpp` — refcount mutations at lines ~1026-1029

4a. Add a small RAII-free atomic refcount helper (header-inline, zero-alloc):
```cpp
static inline void vnode_ref_inc(vfs::Vnode *vn) {
    if (vn) __atomic_fetch_add(&vn->refcount, 1, __ATOMIC_RELAXED);
}
/// @return true if this call brought refcount to zero.
static inline bool vnode_ref_dec(vfs::Vnode *vn) {
    if (!vn) return false;
    return __atomic_fetch_sub(&vn->refcount, 1, __ATOMIC_ACQ_REL) == 1;
}
```
Place in `vfs.hpp` (needs `<types.hpp>` only; `__atomic_*` are builtins).

4b. `FdTable::free`/`free_err` zero-check uses the *return value*:
```cpp
if (fds[fd].vnode) {
    if (vnode_ref_dec(fds[fd].vnode)) {
        if (fds[fd].vnode->ops->close)
            fds[fd].vnode->ops->close(*fds[fd].vnode);
    }
}
```
(Remove the old `> 0` / re-read pattern entirely — the `else` branch that
closed unconditionally was a defence for a corrupted state; with atomic
refcount the prev==1 branch is the sole close trigger. Document the
semantic change: an already-zero refcount no longer forces close.)

4c. `sys_dup` / `sys_dup2` (fs.cpp:378-379, 466-467):
```cpp
if (old->vnode) vnode_ref_inc(old->vnode);
```

4d. `sys_chdir` (fs.cpp:411-414): guard the `cwd_vnode` swap with
`cwd_lock_`:
```cpp
sync::SpinLockGuard guard(cur->cwd_lock_);
if (cur->cwd_vnode) vnode_ref_dec(cur->cwd_vnode);
cur->cwd_vnode = vn;
vnode_ref_inc(vn);
```
Add `sync::SpinLock cwd_lock_;` to `TaskControlBlock` (task.hpp). Check
`SpinLockGuard` exists in `sync/spinlock.hpp`; if only `SpinLock` + manual
lock/unlock, use manual lock/unlock to match surrounding code.

4e. `task.cpp` refcount sites (139, 864-865, 1216-1218, 1297-1298) and
`shell.cpp` (1026-1029) converted to `vnode_ref_inc`/`vnode_ref_dec`.

**Caveats:** `std::atomic` unavailable — use builtins (see Principle 6).
The `> 0` pre-checks in the audit's call sites are obsolete once the dec is
atomic; dropping them is intentional. `SpinLock` is in
`kernel/sync/spinlock.hpp`; check exact namespace/class names before use.
`FdTable::free` callers: `sys_close`, `exec_into_current`, task cleanup —
semantics unchanged.

### Step 5 — VULN-H1: per-segment W^X page permissions

**Files:**
- `src/kernel/memory/vmm.hpp` / `vmm.cpp` — `map_page_in_pml4` overload with
  permission bitmask
- `src/kernel/elf/elf.cpp` — `load_segments_and_stack`

5a. Add to vmm.hpp:
```cpp
enum class PageFlags : uint8_t { Writable = 1, Executable = 2 };
```
and an overload of `map_page_in_pml4` taking `PageFlags flags`
(defaulting to `Writable | Executable` to preserve existing callers), which
sets/clears the architectural NX bit (x86_64: bit 63; aarch64: bit 54;
riscv64: bit 63) in the PTE whenever `Executable` is absent.

5b. In `load_segments_and_stack` (elf.cpp:203-207), derive per-segment flags:
```cpp
using VMM::PageFlags;
PageFlags flags = static_cast<PageFlags>(
    ((phdr->flags & 0x2) ? static_cast<uint8_t>(PageFlags::Writable) : 0) |
    ((phdr->flags & 0x1) ? static_cast<uint8_t>(PageFlags::Executable) : 0));
VMM::map_page_in_pml4(vaddr_base + page_idx * arch::PAGE_SIZE,
                      seg_phys + page_idx * arch::PAGE_SIZE, flags, pml4);
```

5c. Stack (elf.cpp:230-234) and heap (elf.cpp:245-248) mappings pass
`PageFlags::Writable` **only**.

**Caveats:** existing callers of `map_page_in_pml4` (task.cpp, vmm.cpp,
fork code, tests) must compile unchanged — the overload default preserves
the old writable+executable behaviour. `phdr->flags & 0x2` is `PF_W`,
`& 0x1` is `PF_X` (matches the existing W^X check at elf.cpp:130).
Ensure the underlying PTE writer honours the NX bit for both 4KiB and 2MiB
mappings (check `map_page_in_pml4` implementation).

### Step 6 — VULN-H2: OOB ELF read via `phdr->offset+filesz`

**Files:**
- `src/kernel/elf/elf.cpp` — `validate_segment`, `load_segments_and_stack`,
  `load`, `exec_into_current`
- `src/kernel/syscall/syscall_handlers_process.cpp` — `sys_exec`

6a. `validate_segment(const ELF64ProgramHeader *phdr, uint64_t file_size)`:
after the existing overflow check (line 104), add:
```cpp
if (phdr->offset + phdr->filesz > file_size) return false;
```

6b. Thread `file_size` through `load_segments_and_stack(..., uint64_t
file_size)` and both call sites (`load` and `exec_into_current`).

6c. `sys_exec` passes the actual bytes read: `static_cast<uint64_t>(r)` (the
`read()` return, which is guaranteed `== vn->size` by the existing check at
process.cpp:150). `load()` has no file-size parameter today — add one, or
derive from the header (`phnum * phentsize` is not authoritative). **Add an
explicit `file_size` parameter to `load()`** and update its callers
(search for `elf::load(`).

**Caveats:** `load()` callers are in initrd/vfsd and tests — update all.
The 4-MiB `phdr->offset` heuristic (elf.cpp:127) remains as a secondary
guard.

### Step 7 — VULN-H4/W1: bounded `validate_argv_envp`

**File:** `src/kernel/syscall/syscall_handlers_process.cpp`

7a. Add constants (process.cpp, near top):
```cpp
static constexpr size_t MAX_EXEC_ARGS = 64;
static constexpr size_t MAX_EXEC_ARG_LEN = SYSCALL_MAX_PATH; // 256
```

7b. Rewrite `validate_argv_envp` to (a) bound the entry count, (b) validate
the *full* `MAX_EXEC_ARG_LEN` window via `checked(*p, MAX_EXEC_ARG_LEN)`
before scanning, (c) cap each string at `MAX_EXEC_ARG_LEN`, and (d) return
the accumulated `argv+envp` byte total via an out-parameter for Step 8.
Signature:
```cpp
static bool validate_argv_envp(const char *const *ptr, bool is_user_task,
                               uint64_t *out_total_len = nullptr);
```

**Caveats:** `checked(ptr, 1)` currently validates a single pointer entry;
the new code must still validate each successive `*p` entry pointer (the
`while (*p)` advancement) with `checked(p, 1)` before dereferencing, then
validate the string window. Keep `nullptr` → success (returns 0 length).

### Step 8 — VULN-U2: `setup_user_stack` underflow

**Files:**
- `src/kernel/elf/elf.cpp` — `setup_user_stack`, `load`, `exec_into_current`

8a. `setup_user_stack` returns `0` on failure (currently returns `uint64_t`
RSP):
```cpp
constexpr uint64_t kStackReserve = 512;
if (str_total + kStackReserve >= mem::STACK_SIZE) return 0;
```

8b. `exec_into_current` (elf.cpp:465):
```cpp
uint64_t user_rsp = setup_user_stack(ustack_phys, argv, envp);
if (user_rsp == 0) { VMM::free_user_pages(new_pml4); ... return false; }
```
(free the new page table + stack/heap pages on the failure path — check how
`load_segments_and_stack` failure is handled for the pattern).

8c. `load` (elf.cpp:403) passes `nullptr, nullptr` → `str_total == 0`, never
fails; still check the return for uniformity.

**Caveats:** the 512-byte reserve is stack space for the pointer arrays and
alignment (argc ≤ 64 argv + 64 envp pointers = 1024 bytes worst case — the
reserve must cover the pointer-array region; if 512 is insufficient for the
arrays, raise it; the check is a hard ceiling, not a precise layout
calculation).

### Step 9 — VULN-W2: bounded blocking `tty_read`/`kbd_read`

**File:** `src/kernel/vfs/devfs.cpp` — `tty_read` (lines ~50-74),
`kbd_read` (lines ~245-262).

9a. Replace the `for (retry = 0; retry < UINT64_MAX; ...)` spin with the
cooperative pattern used in `sys_receive` (handlers_ipc.cpp:69-81):
```cpp
while (true) {
    if (serial_has_data()) { ... return 1; }
    if (arch::Keyboard::getchar(key_char)) { ... return 1; }
    if (self.private_data &&
        (reinterpret_cast<uint64_t>(self.private_data) & O_NONBLOCK))
        return VFS_INVALID;
    auto *cur = kernel::Scheduler::current_task();
    if (!cur) return VFS_INVALID;
    cur->state = TaskState::BLOCKED;
    kernel::Scheduler::reschedule();
    if (cur->page_table_) { arch::sti(); arch::hlt(); arch::cli(); }
}
```
Add includes for `kernel/task/scheduler.hpp`, `kernel/task/task.hpp`.

**Caveats:** `tty_read`/`kbd_read` run in the calling task's context — the
`current_task()` is the blocked reader, so `reschedule()` + `hlt` is safe.
Non-blocking mode returns `VFS_INVALID` unchanged. The serial/`Keyboard`
data-ready paths are checked every wake-up, so a serial character arriving
between checks is still seen. Verify no caller relies on `read` returning
after a bounded time.

## 6. Out of Scope / Deferred (documented)

- Full object-lifetime locking for path operations (TOCTOU-window closure
  only, not operation-duration locking).
- Kernel-task↔kernel-task page isolation (ROADMAP v0.4.x, memory-protection
  spec).
- Threaded IRQ wait/notify for `tty`/`kbd` (preferred W2 fix when the IRQ
  infrastructure matures; the reschedule-loop is the v0.3.6 minimum-viable
  fix).
- Pipe `refcount` (int, internal to pipe.cpp, single-writer) — not part of
  the audited Vnode refcount surface.
